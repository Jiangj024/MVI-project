看完代码了，发现了几个**比文档里讨论的更紧急的问题**。有些是直接影响当前结果可靠性的，建议优先修。

---

**最关键的问题：数据泄露 — KFold 是按图像切分的，不是按患者切分的**

这是目前代码里最严重的bug。看你的 `vit2.py` 第229行：

```python
for fold, (train_idx, test_idx) in enumerate(kf.split(base_dataset)):
```

`base_dataset` 的每条数据是一张图像，而同一个患者有多张图（grey/ap/pp/lp，平均约4张）。KFold 直接在图像上切分，意味着同一个患者的 ap 可能在训练集，pp 可能在测试集。模型在训练时见过这个患者的影像风格和临床数据，测试时再见到同一患者的另一张图，AUC当然会偏高。这会让你汇报的 0.76 AUC 是**虚高**的，真实性能可能低不少。

修法很简单：先按 `patient_id` 分组，再对患者做KFold：

```python
unique_patients = list(set([path.split('_')[0] for path in ...]))
kf.split(unique_patients)  # 按患者切分
```

然后再把该患者的所有图像划入同一fold。这个必须最先修，否则后面所有实验结果的baseline都不可信。

---

**第二个问题：临床特征没做归一化**

只有 `年龄` 做了 Z-score，但其他20个特征完全没归一化。甲胎蛋白均值4390，异常凝血酶原均值8044，而性别是0/1，HBV是0/1。这些数量级差了四个量级的特征直接喂进MLP，梯度几乎完全被大数值特征主导。小数值特征（性别、HBV）基本没有学习信号。

所有连续型临床特征都应该做Z-score标准化，或者用MinMaxScaler。而且 `fillna(0)` 对临床数据也不太合理——AFP为0在临床上是有意义的（极低），建议用中位数填充或者加一个 `is_missing` 标志列。

---

**第三个问题：当前代码根本没有多时相建模**

你的文档里花了大量篇幅设计"多时相时序Transformer"，但实际代码里 `MultimodalDataset` 的每条数据是一张单独的图像，完全没有按患者×时相来组织。模型不知道哪几张图属于同一个患者，更不知道图像是grey还是ap。所以文档里说"现有模型将多时相图像视为独立样本"——这不是设计选择，而是数据加载器就没实现多时相的逻辑。

在写时序Transformer之前，首先需要重构 `Dataset`，让每条数据是一个患者的4张时相图（如果缺某个时相要处理缺失），输出 shape 是 `[4, 3, 224, 224]`。

---

**第四个问题：WeightedRandomSampler + class_weights=[1.0, 1.0] 是矛盾的**

`vit2.py` 第238-240行用了 `WeightedRandomSampler` 来平衡采样，但第249行的损失函数 `class_weights = [1.0, 1.0]`——这意味着采样已经平衡了正负样本数量，但损失函数没给正样本额外权重。而你文档里说最优配置是 `class_weights=[1.0, 3.0]`，代码里没有体现。另外根据你文档里的经验总结，WeightedRandomSampler 本身会导致过拟合（SEN=0.846, SPE=0.469），但代码里还在用。

### 修改2：所有连续型临床特征做 Z-score 标准化

**文件**: `vit2.py` 和 `resnet18.py` 中的 `clean_clinical_data()` 函数

**问题**: 当前只有"年龄"做了Z-score，甲胎蛋白（均值~4390）、异常凝血酶原（均值~8044）等特征和性别（0/1）数量级差4个量级，MLP梯度被大数值特征主导。

**具体修改**:

在 `clean_clinical_data()` 中，年龄标准化那行之后，加上对所有连续型特征的标准化：

```python
# 区分二分类特征和连续型特征

continuous_cols = [col for col in feature_cols if col not in binary_cols]

# 对所有连续型特征做 Z-score 标准化
for col in continuous_cols:
    mean_val = df_clinical[col].mean()
```

### 修改5：重构 Dataset 支持多时相输入（为时序Transformer做准备）

**文件**: `vit2.py`，新建一个 `MultiPhaseDataset` 类

**问题**: 当前 `MultimodalDataset` 每条数据是一张图像，没有按患者×时相组织。做时序Transformer之前必须先改数据加载。

**具体修改**:

新增一个 `MultiPhaseDataset` 类（不删原来的，先共存），逻辑如下：

```python
class MultiPhaseDataset(Dataset):
    """
    每条数据 = 一个患者的4个时相图像 + 临床特征 + 标签
    输出 images: [4, 3, 224, 224], clinical: [num_features], label: int
    """
    def __init__(self, root_dir, clinical_dict, transform=None):
        self.transform = transform
        self.samples = []  # list of (patient_id, label, {phase: img_path}, clinical_vector)
        
        # 按患者ID分组收集所有图像
        patient_images = {}  # {patient_id: {phase_name: img_path}}
        patient_labels = {}
        
        for folder_name, label in FOLDER_MAPPING.items():
            folder_path = os.path.join(root_dir, folder_name)
            if not os.path.isdir(folder_path):
                continue
            for img_name in os.listdir(folder_path):
                if not img_name.lower().endswith(('.png', '.jpg', '.jpeg')):
                    continue
                patient_id = img_name.split('_')[0]
                # 从文件名中解析时相名称，具体的 split 逻辑需要根据
                # 实际文件命名格式调整，比如 "ZS10168702_ap.png" → phase = "ap"
                # 请根据实际文件名格式修改下面这行
                phase = img_name.split('_')[1].split('.')[0].lower()
                
                if patient_id not in clinical_dict:
                    continue
                    
                if patient_id not in patient_images:
                    patient_images[patient_id] = {}
                    patient_labels[patient_id] = label
                patient_images[patient_id][phase] = os.path.join(folder_path, img_name)
        
        # 定义标准时相顺序
        self.phase_order = ['grey', 'ap', 'pp', 'lp']
        
        for pid, phase_dict in patient_images.items():
            self.samples.append({
                'patient_id': pid,
                'label': patient_labels[pid],
                'phase_paths': phase_dict,
                'clinical': torch.tensor(clinical_dict[pid])
            })
    
    def __len__(self):
        return len(self.samples)
    
    def __getitem__(self, idx):
        sample = self.samples[idx]
        images = []
        for phase in self.phase_order:
            if phase in sample['phase_paths']:
                img = Image.open(sample['phase_paths'][phase]).convert('RGB')
            else:
                # 缺失时相用黑图填充（也可以用该患者其他时相的均值）
                img = Image.new('RGB', (224, 224), (0, 0, 0))
            if self.transform:
                img = self.transform(img)
            images.append(img)
        
        images = torch.stack(images, dim=0)  # [4, 3, 224, 224]
        return images, sample['clinical'], sample['label']
```

**重要**: 这个类里 `phase = img_name.split('_')[1].split('.')[0]` 这行解析时相名的逻辑，取决于你实际的文件命名格式。你需要告诉 Claude Code 你的图片文件名长什么样（比如 `ZS10168702_ap.png` 还是 `ZS10168702_ap_001.png`），让它调整解析逻辑。

同时需要修改 KFold 切分——用 `MultiPhaseDataset` 后每条数据就是一个患者了，可以直接 `kf.split(dataset)` 不用再手动按患者分组。
