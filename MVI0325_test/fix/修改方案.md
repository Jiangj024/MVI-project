## 文件命名规则（关键上下文）

图像文件位于 `0325processed/0_MVI_Negative/` 和 `0325processed/1_MVI_Positive/` 下，命名格式：

```
{患者ID}_{时相}_{造影剂}_crop.jpg    # 造影增强时相
{患者ID}_grey_crop.jpg               # 灰阶基线（无造影剂后缀）
```

示例：
```
ZS09010040_ap_sonovue_crop.jpg    → 患者ZS09010040, 时相ap, 造影剂sonovue
ZS09010040_grey_crop.jpg          → 患者ZS09010040, 时相grey
ZS09010040_lp_sonovue_crop.jpg    → 患者ZS09010040, 时相lp
ZS09010040_pp_sonovue_crop.jpg    → 患者ZS09010040, 时相pp
ZS09222749_ap_sonazoid_crop.jpg   → 患者ZS09222749, 时相ap, 造影剂sonazoid
ZS09222749_lp_sonazoid_crop.jpg   → 患者ZS09222749, 时相lp, 造影剂sonazoid
```

**解析规则**:
- `patient_id = filename.split('_')[0]` → 正确
- `phase = filename.split('_')[1]` → 得到 grey / ap / pp / lp
- 同一患者同一时相可能有多张图（不同造影剂：sonovue vs sonazoid）

## Step 1: 修复数据泄露 — KFold 按患者切分

### 问题

当前所有脚本中 `KFold` 直接对图像索引切分。同一患者有 4-8 张图（4个时相 × 1-2种造影剂），KFold 会把同一患者的不同图像分到训练集和测试集，造成严重数据泄露。当前报告的 AUC=0.76 不可信。

### 修改文件：`vit2.py`

在 `train_multimodal()` 函数中，找到以下代码段：

```python
kf = KFold(n_splits=N_SPLITS, shuffle=True, random_state=42)
# ...
for fold, (train_idx, test_idx) in enumerate(kf.split(base_dataset)):
```

替换为：

```python
# ====== 按患者级别切分，避免数据泄露 ======
all_patient_ids = [os.path.basename(p).split('_')[0] for p in base_dataset.image_paths]
unique_patients = sorted(set(all_patient_ids))
print(f"共 {len(unique_patients)} 个独立患者, {len(base_dataset)} 张图像")

kf = KFold(n_splits=N_SPLITS, shuffle=True, random_state=42)

for fold, (train_p_idx, test_p_idx) in enumerate(kf.split(unique_patients)):
    train_pids = set([unique_patients[i] for i in train_p_idx])
    test_pids = set([unique_patients[i] for i in test_p_idx])
    
    # 根据患者ID映射回图像索引
    train_idx = [i for i, pid in enumerate(all_patient_ids) if pid in train_pids]
    test_idx = [i for i, pid in enumerate(all_patient_ids) if pid in test_pids]
    
    # 验证无泄露
    assert len(train_pids & test_pids) == 0, "数据泄露！训练集和测试集存在相同患者"
    print(f"\n--- Fold {fold+1}/{N_SPLITS} ---")
    print(f"  训练: {len(train_pids)}患者/{len(train_idx)}图像, 测试: {len(test_pids)}患者/{len(test_idx)}图像")
```

后面的 `Subset(base_dataset, train_idx)` 等代码不需要改，因为 `train_idx` 和 `test_idx` 仍然是图像级别的索引。

## Step 2: 临床特征标准化 + 缺失值处理

### 修改文件：`vit2.py` 和 `resnet18.py` 中的 `clean_clinical_data()` 函数

找到这段代码：

```python
df_clinical.fillna(0, inplace=True)
df_clinical['性别'] = df_clinical['性别'].map({'男': 1, '女': 0})
# 年龄标准化
df_clinical['年龄'] = (df_clinical['年龄'] - df_clinical['年龄'].mean()) / df_clinical['年龄'].std()
```

替换为：

```python
# 性别编码
df_clinical['性别'] = df_clinical['性别'].map({'男': 1, '女': 0})

# 区分二分类特征和连续型特征
feature_cols = [col for col in standard_columns if col != '超声号']
binary_cols = ['性别', 'HBV', 'HCV']
continuous_cols = [col for col in feature_cols if col not in binary_cols]

# 缺失值处理：二分类填0，连续型填中位数
for col in binary_cols:
    df_clinical[col].fillna(0, inplace=True)
for col in continuous_cols:
    df_clinical[col].fillna(df_clinical[col].median(), inplace=True)

# 所有连续型特征做 Z-score 标准化（包括年龄）
for col in continuous_cols:
    mean_val = df_clinical[col].mean()
    std_val = df_clinical[col].std()
    if std_val > 0:
        df_clinical[col] = (df_clinical[col] - mean_val) / std_val
    else:
        df_clinical[col] = 0.0  # 标准差为0说明该特征无变化，置零
```

**同时删除**原来单独处理年龄标准化的那行，因为年龄已经包含在 `continuous_cols` 里统一处理了。

## Step 5: 新增 MultiPhaseDataset 类

### 修改文件：`vit2.py`

在现有 `MultimodalDataset` 类之后，新增以下类（不删除原有类，两者共存）：

```python
class MultiPhaseDataset(Dataset):
    """
    患者级别的多时相数据集
    每条数据 = 一个患者的所有时相图像 + 临床特征 + 标签
    
    输出:
        images: [num_phases, 3, 224, 224]  (num_phases=4: grey/ap/pp/lp)
        clinical: [num_features]
        label: int (0 or 1)
    
    处理逻辑:
        - 同一患者同一时相如果有多张图（不同造影剂），随机选一张
        - 缺失时相用零张量填充，同时返回 phase_mask 标记哪些时相存在
    """
    PHASE_ORDER = ['grey', 'ap', 'pp', 'lp']
    
    def __init__(self, root_dir, clinical_dict, transform=None):
        self.transform = transform
        self.samples = []
        
        # 按患者ID分组收集图像路径
        patient_data = {}  # {pid: {'label': int, 'phases': {phase: [path1, path2, ...]}}}
        
        for folder_name, label in FOLDER_MAPPING.items():
            folder_path = os.path.join(root_dir, folder_name)
            if not os.path.isdir(folder_path):
                continue
            for img_name in os.listdir(folder_path):
                if not img_name.lower().endswith(('.png', '.jpg', '.jpeg')):
                    continue
                
                parts = img_name.split('_')
                patient_id = parts[0]
                phase = parts[1].lower()  # grey / ap / pp / lp
                
                if patient_id not in clinical_dict:
                    continue
                if phase not in self.PHASE_ORDER:
                    print(f"警告: 未知时相 '{phase}' in {img_name}, 跳过")
                    continue
                
                if patient_id not in patient_data:
                    patient_data[patient_id] = {
                        'label': label,
                        'phases': {p: [] for p in self.PHASE_ORDER}
                    }
                patient_data[patient_id]['phases'][phase].append(
                    os.path.join(folder_path, img_name)
                )
        
        # 构建样本列表
        for pid, data in patient_data.items():
            self.samples.append({
                'patient_id': pid,
                'label': data['label'],
                'phase_paths': data['phases'],  # {phase: [path_list]}
                'clinical': torch.tensor(clinical_dict[pid], dtype=torch.float32)
            })
        
        # 统计
        phase_counts = {p: 0 for p in self.PHASE_ORDER}
        for s in self.samples:
            for p in self.PHASE_ORDER:
                if len(s['phase_paths'][p]) > 0:
                    phase_counts[p] += 1
        print(f"MultiPhaseDataset: {len(self.samples)} 患者")
        for p in self.PHASE_ORDER:
            print(f"  {p}: {phase_counts[p]}/{len(self.samples)} 患者有该时相")
    
    def __len__(self):
        return len(self.samples)
    
    def __getitem__(self, idx):
        sample = self.samples[idx]
        images = []
        phase_mask = []  # 1=该时相存在, 0=缺失
        
        for phase in self.PHASE_ORDER:
            paths = sample['phase_paths'][phase]
            if len(paths) > 0:
                # 如果同一时相有多张图（不同造影剂），训练时随机选一张，测试时选第一张
                chosen_path = random.choice(paths) if self.transform else paths[0]
                img = Image.open(chosen_path).convert('RGB')
                phase_mask.append(1)
            else:
                # 缺失时相: 创建占位图像（后续会被 mask 掉）
                img = Image.new('RGB', (224, 224), (0, 0, 0))
                phase_mask.append(0)
            
            if self.transform:
                img = self.transform(img)
            else:
                # 如果没有 transform（KFoldDatasetWrapper 会在外面加）
                # 保持 PIL Image 格式
                pass
            images.append(img)
        
        if isinstance(images[0], torch.Tensor):
            images = torch.stack(images, dim=0)  # [4, 3, 224, 224]
        
        phase_mask = torch.tensor(phase_mask, dtype=torch.float32)  # [4]
        
        return images, sample['clinical'], sample['label'], phase_mask
```

同时修改 `KFoldDatasetWrapper` 以兼容新的4元素输出：

```python
class KFoldDatasetWrapper(Dataset):
    def __init__(self, subset, transform=None):
        self.subset = subset
        self.transform = transform
    
    def __getitem__(self, index):
        items = self.subset[index]
        if len(items) == 3:
            # 旧版: (image, clinical, label)
            x, c, y = items
            if self.transform:
                x = self.transform(x)
            return x, c, y
        elif len(items) == 4:
            # 新版: (images, clinical, label, phase_mask)
            imgs, c, y, mask = items
            if self.transform:
                if isinstance(imgs, torch.Tensor):
                    # 已经是tensor，不需要transform
                    pass
                else:
                    # imgs 是 list of PIL Images
                    imgs = torch.stack([self.transform(img) for img in imgs], dim=0)
            return imgs, c, y, mask
    
    def __len__(self):
        return len(self.subset)
```

### 重要说明

这个 `MultiPhaseDataset` 暂时不替换训练流程，仅作为新增类存在。等 Step 1-4 修完并跑完 baseline 之后，再用它来替换 `MultimodalDataset` 做时序 Transformer 的实验。

## Step 6: 新增工具函数 — 患者级别评估

### 修改文件：`vit2.py`

当前用 `MultimodalDataset`（图像级别）时，同一患者的多张图各自独立预测。最终评估应该是患者级别的：把同一患者所有图像的预测概率取平均，然后再算 AUC/SEN/SPE。

在验证阶段的代码之后，加一个患者级别聚合：

```python
# 在验证循环结束后，y_true, y_prob, y_pred 已经收集完毕
# 新增：患者级别聚合
test_patient_ids = [os.path.basename(base_dataset.image_paths[i]).split('_')[0] for i in test_idx]

from collections import defaultdict
patient_probs = defaultdict(list)
patient_labels = {}
for pid, prob, true_label in zip(test_patient_ids, y_prob, y_true):
    patient_probs[pid].append(prob)
    patient_labels[pid] = true_label

# 患者级别：同一患者所有图像概率取平均
patient_y_true = []
patient_y_prob = []
for pid in patient_probs:
    patient_y_true.append(patient_labels[pid])
    patient_y_prob.append(np.mean(patient_probs[pid]))

patient_y_pred = [1 if p > 0.5 else 0 for p in patient_y_prob]

# 用患者级别指标替代图像级别指标
val_auc_patient = roc_auc_score(patient_y_true, patient_y_prob)
val_acc_patient = accuracy_score(patient_y_true, patient_y_pred)
tn_p, fp_p, fn_p, tp_p = confusion_matrix(patient_y_true, patient_y_pred, labels=[0, 1]).ravel()
val_sen_patient = tp_p / (tp_p + fn_p + 1e-6)
val_spe_patient = tn_p / (tn_p + fp_p + 1e-6)
```

然后用 `val_auc_patient` 作为模型选择标准（替代原来的 `val_auc`），并把两套指标都 print 出来方便对比：

```python
if (epoch+1) % 10 == 0 or epoch == EPOCHS - 1:
    print(f"Epoch [{epoch+1}/{EPOCHS}] Loss: {train_loss:.4f}")
    print(f"  图像级别 AUC: {val_auc:.4f} | 患者级别 AUC: {val_auc_patient:.4f}")
```
