# 医学预训练权重使用说明

## 📋 概述

`vit2_medical_pretrain.py` 是一个尝试使用医学影像预训练权重的训练脚本，旨在提升模型在超声图像上的性能。

## 🎯 为什么需要医学预训练权重？

根据 XGBoost Sanity Check 的结果：
- **ImageNet 预训练**: AUC = 0.67（自然图像，domain gap 大）
- **医学预训练**: 预期 AUC = 0.72-0.76（医学影像，domain gap 小）

ImageNet（猫狗汽车）和超声造影图像的 domain gap 很大，医学预训练权重已经学到了医学影像的特征（组织回声纹理、病灶边界等），更适合超声图像任务。

## 📥 获取医学预训练权重

### 方案1：RadImageNet（推荐）✅

**为什么推荐 RadImageNet？**
- 在大规模放射影像数据集上预训练
- **包含超声图像**
- 已被证明在医学影像任务上效果好

**下载步骤**：

1. **访问 RadImageNet 官网**
   - GitHub: https://github.com/BMEII-AI/RadImageNet
   - 论文: https://pubs.rsna.org/doi/10.1148/ryai.210315

2. **下载 ViT-B/16 预训练权重**
   - 模型: `vit_base_patch16_224`
   - 格式: PyTorch (.pth)

3. **创建目录并放置权重**
   ```bash
   mkdir -p /home/fuxiangyu/jlx/MVI/pretrained_weights
   cp your_downloaded_weights.pth /home/fuxiangyu/jlx/MVI/pretrained_weights/radimagenet_vit_base_patch16_224.pth
   ```

### 方案2：其他医学预训练模型

**BiomedCLIP**:
- 在 PubMed 医学图像-文本对上预训练
- Hugging Face: `microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224`
- 需要安装 `transformers` 库

**MedCLIP**:
- 医学影像 CLIP 预训练
- 需要特殊处理

## ⚠️ 注意事项

1. **权重文件路径**
   - 必须放在：`/home/fuxiangyu/jlx/MVI/pretrained_weights/`
   - 文件名必须是：`radimagenet_vit_base_patch16_224.pth`

2. **权重文件格式**
   - 必须是 PyTorch 格式（.pth）
   - 必须是 ViT-B/16 架构
   - 输出维度必须是 768

3. **如果加载失败**
   - 检查文件路径是否正确
   - 检查文件是否损坏
   - 查看错误信息，可能需要调整 `state_dict` 的 key

## 🛠️ 故障排除

### 问题1：找不到权重文件

```bash
# 检查目录是否存在
ls -la /home/fuxiangyu/jlx/MVI/pretrained_weights/

# 检查文件权限
chmod 644 /home/fuxiangyu/jlx/MVI/pretrained_weights/radimagenet_vit_base_patch16_224.pth
```

### 问题2：权重加载失败

可能原因：
- 权重文件的 `state_dict` key 不匹配
- 需要修改 `vit2_medical_pretrain.py` 中的加载代码

解决方法：
```python
# 查看权重文件的 keys
state_dict = torch.load(radimagenet_path, map_location='cpu')
print(state_dict.keys())

# 根据实际情况调整加载方式
self.vit.load_state_dict(state_dict, strict=False)
```
