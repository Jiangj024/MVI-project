# MVI 微血管侵犯预测项目技术分析报告

## 一、任务定位

### 1.1 临床背景
- **任务目标**：基于超声造影（CEUS）图像预测肝细胞癌（HCC）的微血管侵犯（MVI）状态
- **临床意义**：MVI 是影响肝癌预后和治疗方案选择的关键病理指标
- **数据来源**：
  - 图像数据：`MVI_ceus0325/0325processed`（经过 ROI 裁剪的超声图像）
  - 临床数据：`MVI_ceus0325/0325data/MVI0.xlsx` 和 `MVI1.xlsx`（阴性/阳性患者临床表格）

### 1.2 分类任务
- **类别定义**：二分类任务（MVI 阴性 vs MVI 阳性）
- **数据组织**：
  - `0_MVI_Negative`：阴性样本（标签 0）
  - `1_MVI_Positive`：阳性样本（标签 1）

## 二、技术路线演进

### 2.1 阶段一：纯图像模型（resnet18.py - 未读取）
基于 ResNet18 的单模态图像分类

### 2.2 阶段二：ViT 图像模型（0318vit2.py）
**核心思想**：采用 Vision Transformer 替代 CNN，引入极限防过拟合策略

**关键技术**：
1. **模型架构**：ViT-B/16（ImageNet 预训练）
2. **极限冻结策略**：仅解冻最后 1 个 Encoder Block
3. **防过拟合组合拳**：
   - MixUp 数据增强（α=0.4）
   - Label Smoothing（0.1）
   - 高权重衰减（0.05）
   - AdamW 优化器
   - 超小学习率（5e-5）
4. **类别不平衡处理**：WeightedRandomSampler

### 2.3 阶段三：多模态融合（vit2.py + resnet18.py）
**核心思想**：Late Fusion 架构，融合图像特征与临床表格数据

#### 2.3.1 MultiModal-ViT（vit2.py）
**临床特征工程**：
- **特征维度**：21 维临床指标（完整版）或 5 维核心特征（精简版）
- **核心 5 维特征**：甲胎蛋白、异常凝血酶原、HBV、年龄、性别
- **数据预处理**：
  - 性别编码：男=1，女=0
  - 年龄标准化：Z-score 归一化
  - 缺失值填充：0

**网络架构**：
```
图像分支：ViT-B/16 (768D) → 仅解冻最后1层
临床分支：21D → Linear(32) → BN → ReLU → Dropout(0.3) → Linear(64) → ReLU
融合层：Concat(768 + 64 = 832D) → Dropout(0.5) → Linear(128) → BN → ReLU → Dropout(0.3) → Linear(2)
```

**训练策略**：
- 损失函数：CrossEntropyLoss（label_smoothing=0.1）
- 优化器：AdamW（分层学习率：ViT 1e-5，临床/分类器 1e-4）
- 权重衰减：0.05
- 学习率调度：CosineAnnealingLR（T_max=50，eta_min=1e-6）
- 样本均衡：WeightedRandomSampler

#### 2.3.2 MultiModal-ResNet18（resnet18.py）
**核心差异**：
- **图像分支**：ResNet18（512D）→ 解冻 layer3 + layer4
- **临床分支**：5D → Linear(16) → BN → ReLU → Dropout(0.3) → Linear(32) → ReLU
- **融合维度**：512 + 32 = 544D
- **类别权重**：[1.0, 3.0]（重点惩罚阳性漏诊）
- **优化器**：Adam（统一学习率 1e-4，weight_decay=1e-2）

### 2.4 阶段四：集成学习（vitResnet.py）
**核心思想**：双专家会诊 - 决策级软投票融合

**集成策略**：
```python
prob_ensemble = (prob_vit + prob_resnet) / 2.0
pred_ensemble = (prob_ensemble > 0.5).long()
```

**关键要点**：
1. 严格保持 5-Fold 划分一致性（random_state=42）
2. 分别加载两个多模态模型的最佳权重
3. 对每个测试样本提取两个模型的阳性概率
4. 简单平均后进行最终决策

## 三、框架细节分析

### 3.1 数据处理流程

#### 3.1.1 临床数据清洗（clean_clinical_data）
```python
标准化流程：
1. 读取 MVI0.xlsx 和 MVI1.xlsx
2. 统一列名为 22 个标准字段
3. 合并阴阳性数据
4. 缺失值填充为 0
5. 性别编码：男=1，女=0
6. 年龄 Z-score 标准化
7. 构建 {超声号: 特征向量} 字典
```

#### 3.1.2 多模态数据集（MultimodalDataset）
**匹配逻辑**：
- 从图像文件名提取患者 ID（`img_name.split('_')[0]`）
- 在临床字典中查找对应特征
- 仅保留同时具有图像和临床数据的样本

**数据增强**：
- **训练集**：Resize(224) → 随机水平翻转 → 随机仿射变换(±15°) → 颜色抖动 → 归一化
- **测试集**：Resize(224) → 归一化（无增强）

### 3.2 交叉验证策略

**5-Fold 严格划分**：
```python
kf = KFold(n_splits=5, shuffle=True, random_state=42)
```

**关键保证**：
1. 每次运行的 Fold 划分完全一致
2. 集成评估时必须使用相同的测试集
3. 每个 Fold 独立训练并保存最佳模型

### 3.3 类别不平衡处理

#### 方法一：WeightedRandomSampler（0318vit2.py）
```python
class_counts = [count_0, count_1]
class_weights = [1.0/count_0, 1.0/count_1]
sample_weights = [class_weights[label] for label in train_labels]
sampler = WeightedRandomSampler(weights=sample_weights, 
                                num_samples=len(sample_weights), 
                                replacement=True)
```

#### 方法二：类别权重损失（resnet18.py）
```python
class_weights = torch.tensor([1.0, 3.0]).to(DEVICE)
criterion = nn.CrossEntropyLoss(weight=class_weights)
```
**意义**：阳性样本权重 3 倍，强制模型关注少数类，降低漏诊率

### 3.4 防过拟合技术栈

| 技术 | 0318vit2.py | vit2.py | resnet18.py |
|------|-------------|---------|-------------|
| MixUp | ✅ (α=0.4) | ❌ | ❌ |
| Label Smoothing | ✅ (0.1) | ✅ (0.1) | ❌ |
| Dropout | ✅ (0.6) | ✅ (0.5/0.3) | ✅ (0.5/0.3) |
| Weight Decay | ✅ (0.05) | ✅ (0.05) | ✅ (0.01) |
| 层冻结 | 仅解冻最后1层 | 仅解冻最后1层 | 解冻 layer3+4 |
| BatchNorm | ❌ | ✅ | ✅ |

### 3.5 评估指标体系

**核心指标**：
- **AUC**：主要优化目标（模型选择标准）
- **Accuracy**：整体准确率
- **Sensitivity（SEN）**：真阳性率 = TP/(TP+FN)，衡量漏诊率
- **Specificity（SPE）**：真阴性率 = TN/(TN+FP)，衡量误诊率

**最佳模型选择**：
```python
if test_auc > best_auc_in_fold:
    best_auc_in_fold = test_auc
    torch.save(model.state_dict(), f"best_model_fold{fold+1}.pth")
```

## 四、技术亮点总结

### 4.1 架构设计
1. **Late Fusion 范式**：图像和临床特征在高层语义空间融合，符合 2022-2025 顶刊标准
2. **非对称分支设计**：图像分支深度冻结（防过拟合），临床分支轻量级 MLP
3. **分层学习率**：预训练层使用 0.1 倍学习率，新增层使用标准学习率

### 4.2 训练技巧
1. **极限冻结**：ViT 仅解冻 1 个 Block，ResNet 仅解冻 layer3+4
2. **MixUp + Label Smoothing**：双重正则化压制训练集过拟合
3. **AdamW + 高权重衰减**：0.05 的极强 L2 正则
4. **类别权重 3:1**：针对性解决阳性样本漏诊问题

### 4.3 集成策略
1. **异构模型融合**：ViT（全局注意力）+ ResNet（局部卷积）互补
2. **软投票**：概率级融合保留不确定性信息
3. **严格对齐**：确保测试集完全一致

## 六、潜在改进方向

### 6.1 数据层面
1. 临床特征选择：当前使用 5 维核心特征，可尝试基于 SHAP 的特征重要性分析
2. 数据增强：可引入 AutoAugment 或 RandAugment
3. 外部验证集：当前仅内部交叉验证，缺乏独立测试集

### 6.2 模型层面
1. 注意力融合：替换简单 Concat 为 Cross-Attention 或 Gated Fusion
2. 多尺度特征：提取 ViT 多层特征而非仅用最后一层
3. 自监督预训练：在医学图像数据集上进行领域自适应

### 6.3 集成层面
1. 加权投票：学习最优权重而非简单平均
2. Stacking：训练元学习器进行二次融合
3. 多模型集成：加入 EfficientNet、Swin Transformer 等

### 6.4 临床应用
1. 可解释性：引入 Grad-CAM 可视化关键区域
2. 不确定性量化：输出预测置信度
3. 阈值优化：根据临床需求调整敏感性/特异性平衡点
