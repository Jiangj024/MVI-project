# 医学影像“类似内容文献”调研计划与首轮种子检索

## 执行摘要

基于已上传论文可辨识出的主题，本次调研第一锚点设为**肝细胞癌影像学、尤其是肝脏对比增强超声、微血管侵犯预测，以及深度学习 / Transformer / 放射组学与多中心泛化验证**；为避免检索过窄，并行展开四个医学影像子领域：成像获取 / 技术、后处理与 AI 算法、影像诊断与临床应用、质量评价与发布 / 共享。

方法上采用近十年中英文并行检索，优先系统综述 / 元分析、国际指南、顶级期刊与多中心外部验证研究，以**PRISMA 2020、PRISMA\-S、PRESS、CLAIM、TRIPOD\+AI、PROBAST\+AI**作为检索与质量评价框架。文末给出首轮种子文献清单，按子领域列出并标注初步证据等级。

## 1 假设与检索边界

本轮计划明确采用以下假设：

1. 若后续未补充完整论文清单，先以已上传论文自动抽取主题关键词；当前稳定提取核心词：**hepatocellular carcinoma / 肝细胞癌、contrast\-enhanced ultrasound / 对比增强超声、Sonazoid、microvascular invasion / 微血管侵犯、deep learning、transformer、radiomics、cross\-institutional validation**，确保首轮检索贴近主题且可向广义医学影像扩展。

2. 未指定医学影像子领域时，默认分为四组检索：**成像获取 / 成像技术、影像后处理与 AI 算法、影像诊断与临床应用、影像质量评价与发布 / 共享**，覆盖算法、设备流程、临床判读、报告规范、数据共享全维度。

3. 默认时间范围：**2016\-01\-01 至 2026\-05\-04**，语言为中文 \+ 英文；中文优先检索知网，英文优先生物医学与工程数据库。

4. 首轮调研目标为建立**高质量种子文献池**，后续通过滚雪球、引文追踪和主题扩展完成多轮补全，强调 “方向准、证据强、方法可扩展”。

## 2 数据源、优先级与工作流

### 数据库选择

- 英文主检索源：**PubMed/MEDLINE、Web of Science Core Collection、Scopus、IEEE Xplore**

    - PubMed：生物医学主题词与临床研究检索

### 来源优先级

1. 系统综述 / 元分析、国际共识 / 指南

4. 会议摘要、预印本、无充分验证的代码展示或观点文（仅作背景）

- 开放数据 / 代码库：MONAI、nnU\-Net

- 检索规范：按**PRISMA 2020、PRISMA\-S**记录搜索过程，**PRESS**原则审阅检索式，降低漏检与偏差。

## 4 纳入排除标准与证据等级

### 纳入标准

- 同行评审、2016 年后发表、中英文文献

- 系统综述 / 元分析、指南 / 共识、多中心研究、前瞻性 / 真实世界研究、方法学论文、技术报告、开放数据 / 代码说明

- 临床 AI 研究需明确：目标任务、参考标准、样本来源、数据划分、性能指标；临床转化研究需有外部 / 时间外 / 多中心验证

### 排除标准

- 仅有摘要无正文、无明确参考标准、样本极小无重复性、概念展示缺验证、重复发表、与医学影像无关、全文不可得

- 纯工程论文与医学影像主线弱、无临床 / 成像任务落点（降级处理）

### 证据等级（五档）

1. **高**：系统综述 / 元分析、国际指南 / 共识、报告规范（CLAIM、TRIPOD\+AI、PROBAST\+AI 等）

2. **中高**：多中心 / 外部验证充分的前瞻性 / 高质量回顾性研究

3. **中**：单中心 / 仅内部验证的观察性 / 方法学研究

4. **低**：案例研究、早期探索、仅方法展示

5. **背景**：观点文、框架文、资源平台介绍、治理倡议文

**核心质量门槛**：外部验证 / 多中心 / 参考标准清晰 / 报告完整；无外部验证研究不评为中高及以上。
